## 字形氛围素材

- 消费组件：`src/components/type-orbit-scene.tsx`
- 文件：`public/images/glyph-atmosphere.png`
- 生成方式：内置 ImageGen，以用户选定的方案 2 为图像参考。
- 实际尺寸：1536 × 1024，PNG RGBA；97.77% 像素完全透明。
- 提示词摘要：独立透明的淡蓝、薰衣草紫与薄荷色字形粒子图层，极稀疏的小型拉丁与中文字形碎片、少量细小圆点、极淡的断续轨道弧线；中心保留大面积透明留白；排除大字样 Aa 字、所有界面、品牌、标题、黑色背景、霓虹、3D 和渐变。适配约 800 × 620 的左侧预览舞台。
- 动效：页面只对该透明图层施加轻微漂浮、指针视差及压缩时的聚拢；大字样仍是可实时切换用户字体的 UI。
